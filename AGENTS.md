# AGENTS.md — ytcpm-website

Website for YTCPM Bot (standalone Windows app for YouTube CPM workflows):
storefront, crypto checkout, customer accounts, admin dashboard, blog.
Live at https://ytcpm.cyou.

## Stack

- Astro 7.4 + TypeScript, SSR. Adapter chosen at build time by
  `DEPLOY_TARGET` (cloudflare default / node / vercel) — see
  `astro.config.mjs`. Primary deploy: Cloudflare Workers via Workers
  Builds (Git-connected to `main`, auto-deploys on push).
- PostgreSQL for orders, accounts, packages, settings (`src/lib/db.ts`,
  idempotent schema on every connection). Customer auth = better-auth;
  admins are a separate `admin_users` table with a signed cookie.
- Node >= 24. Versions in `package.json` are the owner's — do not bump
  or "fix" them (and never run `npm audit fix --force`).

## Single sources of truth — edit there, not at call sites

- SEO / discovery data (URLs, JSON-LD, ads.txt, verification):
  `src/config/site.ts`. Endpoints `src/pages/{sitemap.xml,rss.xml,
  robots.txt,ads.txt,llms.txt}.ts` and `src/components/StructuredData.astro`
  all read from it.
- Packages & prices: the `packages` table, edited in /admin/packages
  (defaults/seed in `src/lib/packages.ts`).
- Payment addresses, download + homepage values: dashboard settings
  (`site_settings`), env vars are only the fallback.
- Env vars: documented in `.env.example`; setup in `PAYMENTS_SETUP.md`.

## Conventions

- No jugaad/hacks — professional, maintainable structure: shared
  components, design tokens in `src/styles/global.css`, generated files
  out of git (`worker-configuration.d.ts` is generated by
  `npm run cf-typegen`).
- Clean URLs everywhere: `trailingSlash: "never"`, `build.format:
  "file"`. Content-collection entries are linked by `post.id`
  (`post.slug` is undefined in this Astro version).
- Bot facts (version, sizes, prices, behavior) come only from the
  owner — never invent them. No BAS/Bablosoft wording anywhere public;
  the bot is a "standalone Windows app". Never document the Developer
  settings tab.
- Private areas (/admin, /account, /pay, /login, /signup) are noindex —
  `BaseHead.astro` detects them by path; error pages pass `noindex`.
- Cloudflare env values belong in **Runtime variables and secrets**,
  never the build-time section (Workers Builds syncs `wrangler.json`
  and wipes dashboard build vars). Secrets never enter the repo.

## Push rules

- The owner edits repo files directly on GitHub. **Always check the
  remote head first** (`gh.py head`) and never overwrite his edits;
  push only the files you changed (fine-grained PAT helper:
  `~/workspace/custom-connectors/custom.github-pat/bin/gh.py push`,
  NUL-delimited `--paths-file`).
- Test data created during verification (users, orders, screenshots)
  is deleted in the same pass. The owner's real order/account are
  never touched.
- This repo's trio — `AGENTS.md` / `CLAUDE.md` / `MEMORY.md` — must be
  updated on every substantive change, and cross-link the related docs:
  [`README.md`](README.md), [`PAYMENTS_SETUP.md`](PAYMENTS_SETUP.md),
  [`.env.example`](.env.example), [`vercel.json`](vercel.json),
  `src/config/site.ts`.
